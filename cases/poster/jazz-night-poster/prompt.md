# Jazz Night Poster

## Use Case

适合活动海报、音乐节主视觉、酒吧演出宣传图。

## Prompt

```text
Create a vertical vintage-inspired jazz concert poster for an imaginary event called "Blue Hour Sessions". The main visual is a golden saxophone silhouette crossing a deep indigo moon, surrounded by subtle paper grain, smoky stage light, and abstract rhythm lines. Use strong hierarchy with space for the event title at the top, date and venue at the bottom, and a balanced art-deco layout. The color palette is deep indigo, muted gold, ivory, and a small accent of red. The poster should feel elegant, musical, atmospheric, and print-ready.
```

## Negative Constraints

```text
Avoid real artist names, existing festival logos, messy typography, misspelled visible text, low-contrast layout, and overly complex background details.
```

## Suggested Parameters

- Model: GPT Image 2
- Aspect ratio: 2:3
- Style: vintage poster illustration
- Output: png or webp
