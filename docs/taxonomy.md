# Taxonomy

使用稳定分类可以让案例库更容易浏览、搜索和复用。

## Categories

| Category | Description |
| --- | --- |
| `product` | 产品摄影、广告物料、电商视觉 |
| `character` | 人物、角色、头像、游戏或影视概念 |
| `interior` | 室内、建筑、空间、展陈 |
| `poster` | 海报、封面、活动主视觉 |
| `illustration` | 插画、绘本、编辑视觉 |
| `ui` | App、网页、组件、图标 |
| `food` | 食物摄影、菜单、包装 |
| `fashion` | 服装、穿搭、Lookbook |

## Tags

推荐使用这些标签组合描述案例：

- Medium: `photo`、`illustration`、`3d`、`poster`、`ui`
- Lighting: `soft-light`、`studio-light`、`golden-hour`、`neon`
- Composition: `centered`、`flat-lay`、`close-up`、`wide-shot`
- Mood: `minimal`、`warm`、`cinematic`、`playful`
- Domain: `ecommerce`、`game`、`branding`、`editorial`
