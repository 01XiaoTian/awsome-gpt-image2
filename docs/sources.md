## Import Policy

- Prefer open repositories with explicit licenses.
- Preserve author, source URL, license, and image URL in `metadata.json`.
- Use external image URLs unless redistribution rights and storage requirements are clear.
- Avoid copying prompts that rely on private reference images unless the case still makes sense as a reusable template.
- Flag brand, trademark, public-figure, or personal-likeness cases in `rights_notes`.
