# Prompt Writing Guide

高质量图像提示词通常包含七个层次：

1. Subject：主体是什么。
2. Context：主体处在什么环境或使用场景。
3. Composition：镜头、构图、画幅和视觉层级。
4. Material：材质、纹理、细节。
5. Lighting：光线方向、强度、色温。
6. Style：摄影、插画、3D、海报、UI 等风格。
7. Constraints：避免什么，以及必须保留什么。

## Prompt Skeleton

```text
Create a [medium/style] image of [subject] in [context].
The composition is [camera angle/framing/layout].
Use [lighting], [color palette], and [material details].
The image should feel [mood] and be suitable for [use case].
Avoid [negative constraints].
```

## Good Habits

- 用具体名词替代抽象形容词。
- 少堆风格词，多描述画面目标。
- 对文字、Logo、人物脸部和手部提出明确约束。
- 对商业图说明可用区域，例如留白、标题区、按钮区。
